# 汉字王国 — 小学生趣味识字 🎮

通过力导向图谱展示 **736 个汉字** 之间的 **1408 条关联关系**，配合猜字闯关、智能引导、错字复习等功能，让孩子像探险一样认字。

> 打开即用，不需要安装任何软件，不需要服务器。

---

## 🎯 怎么玩

1. 打开页面，看到一张汉字关系网
2. 金色 ⭐? 是系统推荐的「下一个该猜的字」
3. 点击它，从四个候选字中选出正确答案
4. 答对了 → 解锁新字 + 烟花 + 音效
5. 答错了 → 自动记录到错字本，后面可以复习
6. 一步一步，把整张网点亮

## 🧩 数据结构

### 汉字节点（`ALL_NODES`）

每个节点是一个 JavaScript 对象，定义在 `data.js` 中：

```js
{
  id: "字",          // 唯一标识，用汉字本身
  name: "字",        // 简体字
  nameTrad: "字",    // 繁体字
  pinyin: "zi",      // 拼音（小写无调号）
  category: "normal",// 分类：root（一字，唯一根节点）| normal
  oracle: "...",     // 甲骨文/字形解读
  origin: "...",     // 字义起源
  hints: "...",      // 提示线索，用 | 分隔，含 __ 填空
  groupWords: "...", // 组词，用 | 分隔
  idioms: "...",     // 成语，格式：成语::释义，多个用 | 分隔
  riddles: "...",    // 谜语，格式：谜面::谜底
  synonyms: "...",   // 近义词，用 | 分隔
  antonyms: "..."    // 反义词，用 | 分隔
}
```

### 关系连线（`ALL_LINKS`）

```js
{
  source: "字A",       // 起点节点 id
  target: "字B",       // 终点节点 id
  branchName: "关系说明", // 连线上的文字标签
  linkType: "关系类型"   // 七种之一：形似/加笔/减笔/构件/意义/笔数/语音
}
```

所有连线构成无向图，从「一」出发应该能到达任意节点。

## 📐 数据维护逻辑

以下原则用于指导添加新汉字和关系连线，确保数据质量一致。

### 一、添加新字的流程

1. **以一字为起点，链式寻路。** 新字必须至少有一条连线通往主网。如果新字 A 和主网中已有节点没有直接关联，沿着 A 的语义/构件关系找到 B，B 不在主网则继续找 C……直到碰到主网节点为止，把沿途的字全部加入。

2. **一字多联。** 新字应有至少 2 条连线（一条桥接主网 + 一条关联同族字），让网络越来越密。

3. **全连通检查。** 每次添加后确认从「一」出发 BFS 能到达全部节点，不允许出现新孤岛。

### 二、选字范围

- **以小学生常用字为主**，可适当延展至初中语文范围。
- 不加入生僻字。
- 优先选择能和已有节点形成构件/语义关系的字。
- 按字族批量扩展效率最高（如牛字族：牵、牢、牧、特、牲；午字族：许、杵）。

### 三、内容质量标准

**成语：**
- 只收录适合中小学生的成语，释义用简单语言。
- 太生僻、成人化、含暴力/恐怖的成语不留（宁可空缺）。
- 常见俗语/歇后语可保留。

**组词：**
- 选 4-5 个高频常用词。
- 不能保留未完成的填空形式（如 `__水` 应换成完整词）。

**谜语：**
- 格式必须为 `谜面::谜底`，不可缺少 `::`。
- 谜底可以是字形拆解说明。

**提示线索：**
- 用 `__` 填空形式，4-5 条为宜。
- 确保线索中的事实准确（如笔画数、字形描述等）。

**甲骨文解读：**
- 描述字形来源，字数 5-20 字为宜。

### 四、连线关系类型

| 类型 | 含义 | 示例 |
|------|------|------|
| 构件 | A 是 B 的偏旁或部件 | 言→许、木→桃 |
| 意义 | 语义相关（近义/反义/同类） | 红→绿、长→大 |
| 形似 | 字形相近 | 入→人、已→己 |
| 加笔 | A 加一笔变成 B | 十→干、日→目 |
| 减笔 | B 减一笔变成 A | 太→大、玉→王 |
| 笔数 | 笔画数相同 | 少用 |
| 语音 | 读音相同或相近 | 少用 |
