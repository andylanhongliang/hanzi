# 汉字王国 — 小学生趣味识字

一个面向小学生的汉字学习 web 应用。通过力导向图展示 623 个汉字的关联关系，配合猜字闯关、智能引导、错字复习等功能，让识字变得像探险一样有趣。

## 🎮 功能

- **汉字图谱**：可视化 623 个汉字 + 905 条关联（形似/加笔/减笔/构件/意义）
- **战争迷雾**：渐进解锁，每认一个字就点亮一片区域
- **智能引导**：广度优先推荐下一个该猜的字（⭐标记）
- **点选猜字**：候选按钮 + 键盘输入，答对有音效和烟花
- **错字复习**：自动记录答错字，闪卡模式逐个复习
- **多用户**：支持多个孩子各自维护进度
- **移动端适配**：底部抽屉面板，手机也能用

## 🚀 使用

1. 下载所有文件到同一个文件夹
2. 双击 `index.html` 即可开始
3. 或部署到任意静态服务器（GitHub Pages / Vercel / Netlify）

## 📁 文件结构

```
hanzi/
├── index.html        # 主页面
├── app.js            # 游戏逻辑
├── data.js           # 汉字数据（623节点 + 905链接）
├── styles.css        # 样式
├── echarts.min.js    # ECharts 图表库
└── archive/          # 历史版本
```

## 🛠 技术栈

- 纯前端（HTML + CSS + JS），零服务器依赖
- ECharts 力导向图
- localStorage 持久化
- Web Audio API 音效
- Web Speech API 朗读
