# 汉字王国 — 小学生趣味识字 🎮

通过力导向图谱展示 **623 个汉字** 之间的 **905 条关联关系**，配合猜字闯关、智能引导、错字复习等功能，让孩子像探险一样认字。

> 打开即用，不需要安装任何软件，不需要服务器。

---

## 🎯 怎么玩

1. 打开页面，看到一张汉字关系网
2. 金色 ⭐? 是系统推荐的「下一个该猜的字」
3. 点击它，从四个候选字中选出正确答案
4. 答对了 → 解锁新字 + 烟花 + 音效
5. 答错了 → 自动记录到错字本，后面可以复习
6. 一步一步，把整张网点亮

---

## ✨ 主要功能

| 功能 | 说明 |
|------|------|
| 🔗 汉字图谱 | 623 个汉字以力导向图展示，7 种关系连线（形似/加笔/减笔/构件/意义/笔数/语音） |
| 🌫️ 战争迷雾 | 只显示已解锁的字和相邻的「?」待猜字，逐步探索 |
| ⭐ 智能引导 | 自动推荐下一个该猜的字，广度优先，先学完兄弟再学子节点 |
| 🎯 点选猜字 | 四个候选按钮点选，也支持键盘输入，答对答错都有反馈 |
| 📝 错字复习 | 答错的字自动进错字本，闪卡模式逐个复习 |
| 👤 多用户 | 支持多个孩子各自维护学习进度，互不干扰 |
| 📱 移动端 | 手机上也能用，面板自动变为底部抽屉 |
| 🔊 音效 | 答对、答错、里程碑都有专属音效，可一键静音 |
| 🌙 护眼模式 | 暖色主题，晚上也能安心用 |

## 🚀 使用方法

### 电脑上打开

1. 下载所有文件到同一个文件夹
2. 双击 `index.html`
3. 开始探索！

### 手机上打开

1. 把所有文件放到手机里
2. 用浏览器打开 `index.html`
3. 或者部署到 GitHub Pages / Gitee Pages，得到一个网址直接访问

### 部署到公网（免费）

- **GitHub Pages**：上传到 GitHub 仓库，Settings → Pages 开启，得到 `https://你的用户名.github.io/hanzi` 网址
- **Gitee Pages**：国内更快，同样免费

## 🛠 技术细节

- **纯前端**：HTML + CSS + JavaScript，零后端依赖
- **ECharts**：力导向图渲染汉字关系网
- **localStorage**：学习进度保存在浏览器本地，不收集任何用户数据
- **Web Audio**：音效合成，不需要任何音频文件
- **Web Speech**：调用系统语音朗读汉字
